What is LUFS?

LUFS is Loudness Units Full Scale, ITU-R BS.1770-4 / EBU R128. Unlike RMS, it uses K-weighting mimicking human head.

K-weighting

Stage1 high-shelf 1681.97 Hz +3.9998 dB Q0.7072 b0=1.53512485958697 b1=-2.69169618940638 b2=1.19839281085285 a1=-1.69065929318241 a2=0.73248077421585. Stage2 RLB high-pass 38.13 Hz Q0.5003 b0=1 b1=-2 b2=1 a1=-1.99004745483398 a2=0.99007225036621.

Gated blocks

400ms blocks 75% overlap (100ms hop). Absolute gate -70 LUFS removes silence. Relative gate -10 LU below ungated.
