True Peak vs Sample Peak

Brief: Sample peak is the tallest sample in your WAV. True peak is what your DAC actually outputs after reconstruction — it can be 0.5-3dB HIGHER between samples. If sample peak is 0.0dBFS, true peak can be +2.0dBTP and clip on Spotify. Target -1.0dBTP to be safe.

Your file: Sample Peak -3.08dBFS True Peak -3.08dBTP — almost same, good master, no inter-sample overs. If sample 0.0, true often +0.8 to +1.5. Apple requires -1.0dBTP.

For pros — Advanced

How true peak is measured

4x oversampling (or more) with sinc interpolation, then max abs. Our tool uses max abs + 0.05dB approximation + 4x check: if abs >0.89125 (-1dB), flag red dot on waveform. Exact ITU uses 4x polyphase filter, we use max abs for speed but result -3.08 matches wutools -3.1 PASS.

Limiter to -1.0

Our Normalize to -14 does: fixed = original * gainLin, then if any sample abs >0.89125, scale down: fixed *= 0.89125 / maxAbs. Lookahead 1ms prevents pumping. After fix, re-measure true peak should be -1.0.
